# Aetherium OS v0.1.0

The first public developer preview of Aetherium OS, created by Fahd Ahmed.

## Highlights

- Premium Obsidian Prism desktop interface
- Animated startup experience
- Monaco-based professional code editor
- Project explorer, workspace search, and persistent recent projects
- Integrated terminal with run and build controls
- Aether AI with streaming Gemini 3.5 Flash responses
- Explicit active-file, code-selection, project-map, and terminal context
- Git branch and working-tree status
- Command palette, themes, settings, keyboard shortcuts, notifications, and autosave

## Installation

1. Download <code>Aetherium-OS-0.1.0-x64.exe</code>.
2. Run the installer.
3. Windows SmartScreen may display an “Unknown publisher” warning because this preview is not code-signed.
4. To use Aether AI, set <code>GEMINI_API_KEY</code> as a Windows user environment variable and restart Aetherium.
